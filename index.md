# Awesome AI Interior Design Tools

A curated list of AI tools for interior design, room redesign, floor plans,
virtual staging, renovation previews, and real estate visual workflows.

This page mirrors the GitHub repository README so it can also work as a simple
GitHub Pages resource hub.

## Featured Tool

[RoomMaker AI](https://roommakerai.org/) is an AI room designer for photo-based
room redesign, floor plan concepts, virtual staging, renovation previews, and
real estate visual workflows.

Useful RoomMaker AI workflows:

- [Room Redesign](https://roommakerai.org/interior/room-redesign)
- [Floor Plan Generator](https://roommakerai.org/floor-plans/generator)
- [Virtual Staging](https://roommakerai.org/stage/virtual-staging)
- [Listing Image Pack](https://roommakerai.org/listing/image-pack)
