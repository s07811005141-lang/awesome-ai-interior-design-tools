# Contributing

Thanks for helping improve this AI interior design tools list.

## What Fits

Good additions should be directly useful for at least one of these workflows:

- AI room redesign from an existing photo
- Interior style, furniture, or material visualization
- Floor plan generation or layout planning
- Virtual staging and real estate listing visuals
- Renovation, exterior, or property presentation previews

## Entry Format

Use one short description. Keep it practical and neutral.

```md
- [Tool Name](https://example.com/) - Clear description of what the tool helps
  users do.
```

## Quality Rules

- Use the official product URL.
- Do not add affiliate, tracking, or shortened links.
- Do not add duplicate tools.
- Do not add tools with broken public pages.
- Avoid exaggerated claims such as "best", "number one", or "guaranteed".
- Keep descriptions focused on real use cases.

## Pull Request Notes

If you submit a pull request, please include:

- The category where the tool belongs.
- Why it is useful for interior design, floor plans, staging, renovation, or
  real estate visuals.
- Whether you have used it yourself or found it through research.
